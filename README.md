# Koffi
------------------------------
(Kotlin, Jetpack Compose)

• Developed a coffee-ordering Android application featuring Home, Menu, Product, Cart, and Checkout flows using Jetpack Compose and Material Design principles.

• Implemented MVVM architecture with structured UI state management, reusable composables, and navigation components to ensure maintainable and scalable code.

• Integrated local data persistence using Room Database and designed dynamic product rendering, cart management, and order-processing functionality.

• Built responsive user interfaces with reusable components, enabling seamless navigation and consistent user experience across multiple screens.
